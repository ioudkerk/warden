# Warden's built-in breached-password corpus.
#
# This list is small and it is not meant to be comprehensive. Point Warden at a real
# Have I Been Pwned download (security.breached_password_file) for coverage; this
# exists so that the mandatory check in SPEC §7.2 is doing something in a deployment
# that has not done that yet, rather than passing everything while appearing to work.
#
# It is weighted towards passwords of TWELVE CHARACTERS OR MORE, which is not how a
# general top-N list is weighted. The reason is that the default policy already has a
# twelve-character floor, so "123456" and "qwerty" never reach this file — they are
# refused on length. The entries that earn their place are the ones that clear the
# length rule and are still in every wordlist.
#
# Shorter entries are kept for tenants that lower MinLength to the floor of 8.
#
# One password per line. Blank lines and lines beginning with # are ignored.
# Comparison is exact and case-sensitive: the corpus is consulted by SHA-1, so a
# case-insensitive match is not something this format can express.
